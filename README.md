## О проекте

Данный проект представляет собой консольное приложение, разработанное в рамках лабораторной работы №1.

Программа позволяет пользователю выполнять основные расчёты для квадрата по заданной длине его стороны.

Доступны следующие операции:

- расчёт площади;
- расчёт периметра;
- расчёт диагонали;
- повторное выполнение операций без перезапуска программы;
- завершение работы через интерактивное меню.

---

## Вариант задания

**Вариант:** 2

Программа реализует следующие математические операции:

| Операция | Формула |
|:---:|:---:|
| Площадь | `S = a²` |
| Периметр | `P = 4a` |
| Диагональ | `d = a√2` |

где `a` — длина стороны квадрата.

---

## Функциональность

### Площадь

Расчёт площади квадрата:

```text
S = a²
```

Реализовано функцией:

```cpp
double calculateSquare(double a)
```

### Периметр

Расчёт периметра квадрата:

```text
P = 4a
```

Реализовано функцией:

```cpp
double squarePerimeter(double a)
```

### Диагональ

Расчёт диагонали квадрата:

```text
d = a√2
```

Реализовано функцией:

```cpp
double squareDiagonal(double a)
```

Для вычисления квадратного корня используется функция `sqrt()` из библиотеки `<cmath>`.

---

## Интерфейс программы

После запуска пользователю отображается интерактивное меню:

```text
=== Вариант 2: расчёты для квадрата ===

1. Площадь
2. Периметр
3. Диагональ
0. Выход

Выберите пункт:
```

Пользователь выбирает необходимую операцию и вводит длину стороны квадрата.

После получения результата программа возвращается в меню и позволяет выполнить следующий расчёт.

## Пример работы

Пусть длина стороны квадрата равна:

```text
a = 5
```

### Расчёт площади

```text
Выберите пункт: 1
Введите число: 5
Результат: 25
```

### Расчёт периметра

```text
Выберите пункт: 2
Введите число: 5
Результат: 20
```

### Расчёт диагонали

```text
Выберите пункт: 3
Введите число: 5
Результат: 7.07107
```

Для завершения программы:

```text
Выберите пункт: 0
Работа завершена.
```

## Сборка и запуск

### Windows

Для сборки проекта необходим компилятор C++, например GCC / MinGW.

Откройте Git Bash или терминал и перейдите в папку проекта:

```bash
cd ~/lab1-git
```

Скомпилируйте программу:

```bash
g++ main.cpp -o lab1
```

После успешной компиляции запустите программу:

```bash
./lab1
```

В Windows также можно запустить:

```bash
./lab1.exe
```

## Работа с Git

Для разработки использовалась система контроля версий Git и удалённый репозиторий GitHub.

### Проверка состояния

```bash
git status
```

### Создание новой ветки

```bash
git checkout -b lab1
```

### Добавление изменений

```bash
git add .
```

### Создание коммита

```bash
git commit -m "Описание изменений"
```

### Отправка ветки на GitHub

```bash
git push -u origin lab1
```

### Pull Request

После отправки ветки создаётся Pull Request:

```text
lab1 → main
```

Таким образом, изменения из рабочей ветки `lab1` предлагаются для объединения с основной веткой `main`.
